# Участие в разработке

Этот репозиторий — собранный продукт ядра CoLabus. Его содержимое генерирует сборка из репозитория разработки
по списку разрешённого; правки, отправленные сюда напрямую, при следующей сборке пропадут.

- Ошибку или предложение опишите в обсуждении этого репозитория: что вы запускали, что ожидали, что получили, версию
  из `PRODUCT-VERSION.json`.
- Уязвимость — по правилам `SECURITY.md`, не в открытом обсуждении.
- Изменения ядра делаются в репозитории разработки и попадают сюда следующей сборкой продукта.
