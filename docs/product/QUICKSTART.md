# Первый запуск CoLabus

Нужны Node.js 22, git, копия продуктового репозитория `CoLabus` и ваш проект с git.
Перед установкой сохраните изменения проекта коммитом; сначала просмотрите план `--dry-run`.
Замените `<project>` на путь к проекту. Установщик не коммитит результат: проверьте `git diff`.

Пять команд для установки и первой передачи работы:

```powershell
node CoLabus/docs/ops/kernel-install.cjs --target <project> --dry-run
node CoLabus/docs/ops/kernel-install.cjs --target <project>
# Следующие три команды — из корня вашего проекта.
node .ai/bin/protocol-session.cjs start --agent codex
node .ai/bin/protocol-validate.cjs --root .
node .ai/bin/protocol-handoff.cjs record --owner <owner>
```

Владелец ставит одну задачу в `.ai/TASK.md` и назначает роль агента. Агент читает `AGENTS.md`,
задачу, статус git и последние журналы, затем работает в её границах. Если SessionStart уже
открыл сессию, повторный `start` не нужен. `<owner>` — напечатанное имя владельца журнала,
не session id и не имя человека.

До передачи: просмотрите свой `git diff`, выполните тесты проекта, запишите в свой журнал
`.ai/worklog/<owner>.md` результат и оставшиеся вопросы с метками `Agent`, `Action`, `Result`,
`Next step`, `Open`, затем выполните `record`. Зелёный валидатор не заменяет тесты проекта.
Реализатор передаёт результат независимому ревьюеру и сам не объявляет задачу завершённой.
Для правки общих документов сначала возьмите замок по инструкции руководства.
