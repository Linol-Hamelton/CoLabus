# Журнал подтверждений владельца проекта

Журнал `docs/ops/owner-words.md` принадлежит проекту-хозяину. Запись связывает
прямое подтверждение владельца с конкретным действием и проверяемой версией.
Агент записывает подтверждение только после получения его от владельца.

Для каждой записи укажите предмет действия, источник подтверждения, ветку и
полный SHA, если разрешение привязано к коммиту. Смена такого SHA требует
нового подтверждения. Отсутствие записи означает отсутствие подтверждения.

Шаблон создаётся установщиком только при отсутствии файла. Существующие записи
сохраняются. Предложение агента, результат теста и заключение рецензента сами
по себе не являются разрешением владельца.

Решения проекта записываются в `.ai/DECISIONS.md` согласно правилам проекта.
