# Записи слов владельца (Addenda), источник правды для журнала owner-words

Каждое слово владельца сначала записывается здесь отдельным разделом `## Addendum N` (дата, дословная цитата, провенанс: прямое слово или `relayed-via-<agent>`, кто транскрибировал), и только потом появляется производная строка в `docs/ops/owner-words.md` со ссылкой `addendum-ref: docs/ops/OWNER-ADDENDA.md:<номер строки>`.

Раздел только добавляется; запись не переписывается. Слово владельца агент не сочиняет: если слова нет в этом файле, его нет.

Записей пока нет.
